## Command-Line Arguments

```
--data PATH              Path to CSV data file (default: processed_heart_cleveland.csv)
--normalize              Normalize features (default: True)
--no-normalize           Don't normalize features
--hidden-layers N [N...] Hidden layer sizes (default: [32])
--activation {relu,sigmoid,tanh}  Activation function (default: relu)
--learning-rate FLOAT    Learning rate (default: 0.01)
--epochs INT             Number of epochs (default: 100)
--batch-size INT         Mini-batch size (default: 32)
--weight-std FLOAT       Weight init std dev (default: 0.01)
--seed INT               Random seed (default: 42)
--quiet                  Suppress training output
```
